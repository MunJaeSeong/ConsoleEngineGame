# ConsoleEngineGame

## 1. 만들 게임
```markdown
콘솔 문자 화면 위에서 돌아가는 무한 웨이브 디펜스 게임입니다.
플레이어가 제한된 자원으로 방어 유닛을 배치해 적의 공격을 막습니다.

자세한 사항은 [docs/디펜스-게임기획.md](docs/디펜스-게임기획.md)를 확인해주세요.
```

## 3. 파일 구조

게임 엔진은 `ConsoleEngine/`에, 디펜스 게임 프로젝트는 `Program/`에 위치합니다. 상세 구현 문서는 `docs/game/`에 정리되어 있습니다.
