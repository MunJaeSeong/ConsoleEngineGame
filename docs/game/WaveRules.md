# WaveRules.cs

`WaveRules`는 웨이브 진행에 공통으로 적용되는 플레이어 체력, 적 출현 수와 체력 배율을 관리하는 정적 규칙 클래스입니다.

## 기본 규칙

| 항목 | 값 | 설명 |
|---|---:|---|
| `StartingPlayerHp` | 50 | 게임 시작 및 재시작 시 플레이어 체력 |
| `DamagePerArrival` | 1 | 적이 결승점에 도달했을 때 감소하는 체력 |

## 웨이브별 적 출현 수

`GetEnemyCount(wave)`는 웨이브 시작 시 생성할 적의 수를 반환합니다.

```text
출현 수 = 50 + (해당 웨이브 - 1) × 10
최대 출현 수 = 500
```

- 1웨이브: 50마리
- 2웨이브: 60마리
- 46웨이브: 500마리
- 47웨이브 이후: 항상 500마리

웨이브 번호가 1보다 작아지거나 46보다 커져도 첫 물량 구간의 계산 범위로 제한됩니다.

## 웨이브별 적 체력 배율

`GetEnemyHpMultiplier(wave)`는 웨이브에 따라 적용할 체력 배율을 반환합니다.

```text
46웨이브까지 체력 배율 = 100%
47웨이브 이후 보너스 = 웨이브 - 46
체력 배율 = 100% + 보너스%
```

예를 들어 47웨이브는 101%, 48웨이브는 102%의 체력 배율을 적용합니다.

`Enemy`는 이 배율을 각 몬스터의 기본 체력에 곱한 뒤 최대 체력과 현재 체력을 초기화합니다.

```text
최대 체력 = 기본 체력 × 웨이브 체력 배율
```
