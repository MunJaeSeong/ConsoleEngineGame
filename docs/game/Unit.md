# Unit.cs

유닛의 종류, 배치 위치, 강화 단계와 누적 강화 비용을 관리합니다.

## 유닛 역할군

| 역할군 | 종류 |
|---|---|
| 단일 딜러 | Archer, Cannon, Sniper |
| 광역 딜러 | BlastMage, MeteorMage, FrostMage |
| 상태이상 서포터 | SlowTower, StunTower |
| 버프형 | ArmorBreaker, BattleCry |

## 강화 규칙

- 소환 즉시 1단계입니다.
- 목표 단계에 따라 성공 확률이 단계당 8%씩 감소합니다.
- 강화 실패 시 해당 유닛은 즉시 배치 목록에서 제거됩니다.
- 강화 비용은 단계별로 차등 적용됩니다.

강화 성공 확률은 다음 공식으로 계산합니다.

```text
successChance = 100 - (nextStage - 2) * 8
```

즉 2단계는 92%, 10단계는 28%입니다.

## 판매 규칙

판매 금액은 다음 식으로 계산됩니다.

```text
(50 + 누적강화비용 * 60 / 100) * 단계
```

단계와 누적 강화 비용이 높을수록 판매 시 회수되는 다이아가 증가합니다.
