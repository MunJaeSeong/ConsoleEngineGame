# GridMap.cs

`GridMap`은 게임 맵의 크기와 Enemy 이동 경로를 제공하는 정적 데이터 클래스입니다.

## 역할

- 맵의 가로·세로 크기를 상수로 정의합니다.
- Enemy가 이동할 좌표들을 순서대로 저장합니다.
- 여러 클래스가 동일한 맵 정보를 공유하도록 합니다.

## 맵 크기

| 상수 | 값 | 의미 |
|---|---:|---|
| `Width` | `20` | 가로 칸 수 |
| `Height` | `20` | 세로 칸 수 |

왼쪽 위가 `(0, 0)`이고 오른쪽 아래가 `(19, 19)`인 좌표계를 사용합니다.

## 이동 경로

`Path`는 읽기 전용 리스트로 선언된 좌표 배열입니다.

```csharp
public static IReadOnlyList<(int X, int Y)> Path { get; }
```

Enemy는 이 배열을 순서대로 따라 이동합니다.

```text
인덱스 0       시작 지점 S
인덱스 n       다음 이동 위치
마지막 인덱스  목표 지점 G
```

현재 경로는 ㄹ자 형태로 구성되어 있습니다.

```text
S → → → → → → →
                ↓
                ↓
  ← ← ← ← ← ← ← ↓
                ↓
                ↓
                G
```

정확한 좌표는 `GridMap.Path`에 저장된 순서대로 연결됩니다.

## 경로 좌표의 용도

| 위치 | 사용처 |
|---|---|
| `Path[0]` | 시작 지점과 Enemy의 초기 위치 |
| `Path[^1]` | 목표 지점 |
| 중간 요소 | Enemy 이동 경로와 맵 위의 `#` 타일 |

## 주의 사항

- 맵 외부를 피하기 위해 모든 좌표는 `0 <= X < Width`, `0 <= Y < Height` 범위 내에 둬야 합니다.
- 경로 배열의 순서는 곧 Enemy의 이동 순서입니다.
- 시작 지점과 목표 지점은 별도의 변수에 저장되는 것이 아니라 `Path`의 첫 요소와 마지막 요소로 결정됩니다.
