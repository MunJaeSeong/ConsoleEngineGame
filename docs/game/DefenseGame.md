# DefenseGame.cs

`DefenseGame`는 `ConsoleEngine.GameBase`를 상속해 전체 그리드 디펜스 게임 루프를 관리하는 메인 게임 클래스입니다.

## 역할

- 20×20 맵과 상태 표시 영역을 구성합니다.
- 화살표 키로 배치 커서를 이동합니다.
- 유닛 소환, 강화, 판매를 처리합니다.
- 웨이브 시작 및 적 출현을 제어합니다.
- 유닛 공격, 적 이동, 사망, 결승점 도착을 갱신합니다.
- 맵과 상태를 콘솔 화면 버퍼에 렌더링합니다.

## 화면 크기

생성자는 다음 크기의 화면을 사용합니다.

```csharp
base(GridMap.Width, GridMap.Height + 7)
```

결과적으로 가로 20칸, 세로 27칸의 콘솔 화면을 사용합니다.

## 핵심 상태

| 필드 | 설명 |
|---|---|
| `_playerHp` | 플레이어 체력, 초기값 50 |
| `_diamonds` | 보유 다이아, 초기값 500 |
| `_wave` | 현재 또는 다음 웨이브 번호 |
| `_remainingSpawns` | 이번 웨이브에 남은 적 수 |
| `_waveActive` | 웨이브 진행 여부 |
| `_cursorX`, `_cursorY` | 배치 커서 좌표 |
| `_selectedUnit` | 현재 선택한 유닛 종류 |
| `_units` | 배치된 유닛 목록 |
| `_enemies` | 현재 필드 위의 적 목록 |
| `_message` | 화면에 표시할 현재 안내 메시지 |

## 키 입력

| 키 | 동작 |
|---|---|
| 방향키 | 배치 커서 이동 |
| `1`~`0` | 유닛 종류 선택 |
| `Enter` 또는 `Space` | 선택한 위치에 유닛 소환 |
| `U` | 커서 위치의 유닛 강화 |
| `S` | 커서 위치의 유닛 판매 |
| `P` | 다음 웨이브 시작 |
| `R` | 게임 오버 상태에서 재시작 |
| `Esc` | 게임 종료 |

유닛 선택 키는 `1=Archer`, `2=Sniper`, `3=Cannon`, `4=Frost`, `5=Storm`, `6=Bomb`, `7=Volt`, `8=Toxin`, `9=Aura`, `0=Guardian` 순서입니다.

## 소환 규칙

소환 비용은 고정으로 50 다이아입니다.

소환은 다음 조건을 모두 만족해야 합니다.

- 커서 위치가 이동 경로 위가 아닐 것
- 커서 위치에 다른 유닛이 없을 것
- 보유 다이아가 50 이상일 것

소환에 성공하면 유닛이 1단계로 추가되고 다이아 50이 차감됩니다.

## 강화 규칙

강화 비용은 유닛 단계에 따라 계산됩니다.

```text
현재 비용 = 25 + 현재 단계 × 20
성공 확률 = 100 - 현재 단계 × 8
```

강화 성공 시 유닛 단계가 1 증가합니다. 실패 시 비용을 소모한 뒤 유닛이 즉시 사망하고 배치 목록에서 제거됩니다. 최대 단계는 10단계입니다.

## 판매 규칙

유닛을 판매하면 누적 강화 비용과 현재 단계를 반영한 판매 다이아를 회수하고 유닛을 제거합니다. 판매 금액은 `Unit.GetSellValue()`에서 계산합니다.

## 웨이브 흐름

```text
P 키 입력
  ↓
StartWave()
  ↓
적 생성 시작
  ↓
Enemy 이동 및 결승점 도착 판정
  ↓
유닛 공격 및 적 처치
  ↓
남은 적과 출현 대기 적이 모두 0이면 웨이브 클리어
  ↓
다이아 보너스 지급 및 다음 웨이브 번호 증가
```

웨이브 클리어 보너스는 다음과 같습니다.

```text
25 + 웨이브 번호 × 5 다이아
```

## 적 출현

웨이브가 활성화되어 있으면 `0.28초` 간격으로 적을 생성합니다. 출현 적 수와 체력 배율은 `WaveRules`를 사용합니다.

## 공격 처리

매 프레임 모든 유닛의 공격 시간을 누적합니다.

- 공격 간격에 도달하면 사거리 안의 적을 탐색합니다.
- 경로 인덱스가 가장 높은 적을 우선 공격합니다.
- Cannon, Bomb, Storm은 광역 피해를 줍니다.
- 적 처치 시 적의 드랍 다이아를 즉시 지급합니다.
- 적이 결승점에 도착하면 그 적을 제거하고 플레이어 HP를 1 감소합니다.

## 렌더링

렌더링 순서는 다음과 같습니다.

1. 기본 바닥을 `.`로 표시
2. 이동 경로를 `#`로 표시
3. 시작 지점 `S`와 결승점 `G` 표시
4. 배치된 유닛 표시
5. 필드 위 적 표시
6. 배치 커서를 `X`로 표시
7. 하단에 웨이브, HP, 다이아 및 안내 표시

플레이어 HP가 0이면 `GAME OVER - R: Retry`를 표시하고 게임 갱신을 중단합니다.

## 전체 실행 흐름

```text
키 입력
  ↓
Update: 적 출현, 이동, 공격 처리
  ↓
Render: 맵과 상태 갱신
  ↓
Screen.Present: 콘솔 버퍼 출력
```
