# 그리드 디펜스 구현 명세

## 핵심 흐름

1. 게임 시작 시 다이아 500, 플레이어 HP 50으로 초기화합니다.
2. 방향키로 커서를 이동하고 숫자 키로 유닛 종류를 선택합니다.
3. Enter로 경로가 아닌 빈 타일에 유닛을 소환합니다.
4. Space로 웨이브를 시작합니다.
5. 유닛은 사거리 안의 몬스터를 자동 공격합니다.
6. 몬스터 처치 시 보상을 받고, 결승점 도달 시 HP가 1 감소합니다.
7. 웨이브의 모든 몬스터 처치 또는 결승점 도달 처리가 끝나면 다음 웨이브 준비 상태로 전환합니다.

## 화면 표시

- `.`: 빈 설치 가능 타일
- `#`: 몬스터 이동 경로
- `S`: 스폰 지점
- `G`: 결승점
- `*`: 커서
- 유닛 기호: Cyan
- 몬스터 기호: Magenta

## 자동 전투

- 유닛은 공격 간격마다 사거리 내 몬스터를 탐색합니다.
- Cannon 계열과 마법 유닛은 폭발 범위 내 몬스터에 데미지를 줍니다.
- Frost/Slow/Stun 계열은 대상의 이동 속도를 늦춥니다.
- 단계가 높을수록 데미지와 공격 속도가 증가합니다.

## 강화와 판매

- U로 커서 위치 유닛을 강화합니다.
- 강화 실패 시 유닛이 사라집니다.
- S로 커서 위치 유닛을 판매합니다.
- 강화 확률은 2단계 92%에서 10단계 28%까지 단계당 8% 감소합니다.

## 실행

```bash
dotnet run --project Program/GridDefense.csproj
```
